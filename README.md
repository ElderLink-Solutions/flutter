# Flutter Login Simulation with E2E Tests

This repository contains a Flutter application that demonstrates a login flow with comprehensive end-to-end (E2E) integration tests.

## Quick Start

Navigate to the application directory:

```bash
cd elderlink_app
```

See the [elderlink_app/README.md](elderlink_app/README.md) for detailed instructions on running the application and tests.

## Features

- Clean, Material Design login interface
- Form validation
- Simulated authentication with loading states
- Success screen after login
- Logout functionality
- Comprehensive integration tests covering all user flows
